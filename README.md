# Hao XU's personal page.

[Homepage](https://hxwork.github.io/)

The site is plain static HTML (`index.html` + `stylesheet.css`) served by GitHub Pages; `.nojekyll` disables Jekyll processing.
Preview locally with `python3 -m http.server 4001` and open http://localhost:4001/.
